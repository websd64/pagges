# pagges

Счетчик прочитанных страниц за год, месяц, день.
Статистика сбрасывается при начале нового года, месяца или дня.
Вводите количество страниц которые вы прочитали, либо же количество листов умноженое в двое.

## Установка

```bash
git clone https://github.com/websd64/pagges.git
cd pagges
python pagges.py
